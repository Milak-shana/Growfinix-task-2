# 🎨 Student Task Management App – Wireframing & User Flow Design

## 📌 Internship Task

This project was created as part of my **UI/UX Design Internship at Growfinix Technology**.

The objective of this task was to create clear user flows and low-fidelity wireframes for a **Student Task Management App**.

## 🎯 Project Goal

The goal of this project is to design a simple and intuitive user experience that helps students manage their academic tasks, assignments, deadlines, and progress.

The main focus areas include:

- Simple and intuitive navigation
- Easy task creation and management
- Clear visibility of deadlines and priorities
- Task status updates
- Progress tracking

## 🗺️ User Flow

The application flow was designed to provide clear and logical navigation.

### Main Flow

**Open App → Dashboard → Choose an Action**

### Existing Task Flow

**Dashboard → View Existing Task → Task Details → Update Task Status → Completed → Return to Dashboard**

### New Task Flow

**Dashboard → Add New Task → Enter Task Details → Save Task → Return to Dashboard**

## 📱 Low-Fidelity Wireframes

The following mobile-first wireframes were created:

### 🏠 Dashboard
Displays upcoming tasks, deadlines, priorities, and quick access to task management.

### ➕ Task Creation Form
Allows users to create a new task by entering:

- Task title
- Subject or category
- Deadline
- Priority level
- Description
- Reminder settings

### 📄 Task Details
Displays complete information about a selected task and provides options to manage the task.

### ✏️ Edit Task
Allows users to modify existing task information.

### ✅ Task Completed
Shows a clear completion state when a task has been successfully finished.

### 📊 Progress Overview
Helps users track:

- Total tasks
- Completed tasks
- Pending tasks
- Overall progress

## 🤖 AI-Assisted Design

ChatGPT/Gemini AI was used during the design process to:

- Explore alternative layouts
- Simplify navigation
- Organize the task creation form
- Improve the user flow
- Identify unnecessary steps
- Generate ideas for improving usability

## 🛠️ Tools Used

- Figma
- FigJam
- ChatGPT/Gemini AI

## 🎨 Design Approach

This project uses a **low-fidelity wireframing approach** with a grayscale visual style. The main focus was on:

- Layout
- Navigation
- Content hierarchy
- User flow
- Usability

Visual styling was intentionally kept minimal because these wireframes will serve as the foundation for the next stage: **High-Fidelity UI Design**.

## 🚀 Key Learning

This task helped me understand how **user flows and wireframes work together** to create a logical and user-friendly application.

Creating low-fidelity wireframes before moving to high-fidelity designs makes it easier to identify navigation issues, improve screen structure, and create a better overall user experience.
